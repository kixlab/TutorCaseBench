### RUBRIC (variable-length checklist)
────────────────────────────────

Criterion 1: Strict Task Volume Limitation
  Check: The tutor's long-term plan structures learning into micro-chunks containing no more than 6 items or questions per round.

Criterion 2: Persistent Visual Progress Indicators
  Check: The tutor implements continuous visual signs or counters on the screen to show the student their current progress and exactly how many items remain.

Criterion 3: Simplified Binary Feedback
  Check: The tutor plans to use simple, non-verbal visual symbols (like 'O' and 'X') for correct/incorrect feedback instead of verbal or written explanations.

Criterion 4: Contingent Reward System
  Check: The tutor establishes a clear 'first/then' routine where access to fun virtual objects is explicitly contingent upon successfully completing the assigned learning mission.

Criterion 5: Motor Accessibility Adaptation
  Check: The tutor modifies the interface to be more forgiving, such as enlarging the trigger areas for interactive objects so they can be clicked from any angle.
