SCENARIO

The student is working on completing an SG diary reflection about a recent test in the classroom.

──────────────────────────────────────────────
DIALOGUE
──────────────────────────────────────────────

TUTOR: Please fill out the next page in your SG diary reflecting on how you handled the test today.

STUDENT: I don't really like this work. If I've gubbed up doing a test or something, I probably know I could have done better, but writing this is too hard.

STUDENT: (Pushes the diary away) I get frustrated when I don't get help when I need it! If I don't really like the work or it's too hard, I'll just carry on and then get into trouble.
