──────────────────────────────────────────────
SCENARIO
──────────────────────────────────────────────

The student is at playtime and wants to start a game of football using a ball that another boy is currently playing with.

──────────────────────────────────────────────
DIALOGUE
──────────────────────────────────────────────

TUTOR: It is playtime now. You can go outside and choose an activity.

STUDENT: I want to start my own game of football.

STUDENT: I want to play with the ball that boy is playing with.

TUTOR: He is using it right now. What do you think you should do?

STUDENT: (Pushes the other boy hard to the ground to take the ball) If I hurt him, he will stop playing with the ball, then I can use it to start my own game of football.

Question
